swyr 0.2.3

Space icons now come from the Lucide icon set instead of emoji. The space editor has a searchable icon picker, and existing spaces keep a matching icon automatically.

Releases are built and published by GitHub Actions when a version tag is pushed, so every release comes from a clean build.

Quitting always finishes within a few seconds, even when a page process has stopped responding.

Canvases show a thumbnail in the Library as soon as they are created, and the Library updates as you work.

Fixed: text added to a canvas before it finished loading could be lost.
